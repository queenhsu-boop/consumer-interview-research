# 消费者访谈研究助手

帮助消费品团队准备访谈、整理真实访谈材料，弄清消费者怎么买、怎么用、为什么选择或放弃产品，再形成有依据的改进建议。

这是一个可安装到 AI 工具中的 **Skill（工作指引与配套脚本）**。适合品牌、产品、营销和用户研究团队，支持日化、食品饮料等消费品，另附连锁卤味研究提示卡。真实招募和访谈仍由研究团队完成。

## 输入什么，得到什么

| 你现在有什么 | 提供给它什么 | 它帮你产出什么 |
| --- | --- | --- |
| 想研究一个问题 | 产品与业务背景、要做的决策、目标人群、时间和预算限制 | 招募对象及理由、筛选问题、访谈提纲、试访安排 |
| 已经做过访谈 | 脱敏后的文字稿或笔记、受访者编号、访谈日期及必要背景 | 使用和购买过程、共性与差异、需求与困扰、支持原话、反例及待验证建议 |
| 已有研究报告 | 报告；如有，附上对应的原始记录 | 哪些结论有依据、哪些推断过头、如何改写、还缺什么证据 |

可以只让它修改几道问题或审查一条结论。没有真实材料时，它只能准备研究或提出假设；只有摘要笔记时，不应生成“受访者原话”。

## 安装后，直接这样用

将示例中的条件换成你的真实项目；分析材料时把对应文件一并提供给工具。

**准备一次研究：**

```text
请使用 consumer-interview-research。
我们想了解消费者为什么更换洗衣液品牌，用于调整产品和沟通内容。
计划访谈 8 人，每人 40 分钟，目前只能从品牌社群招募。
请先给招募方案、筛选问题和访谈提纲，
说明现有招募渠道会遗漏谁，不要预设换牌原因。
```

**分析已有访谈：**

```text
请使用 consumer-interview-research 分析我提供的脱敏访谈记录。
目标是理解购买、实际使用和复购变化。
请区分共性、差异、反例和未知，每条重要发现标出来源。
涉及原因和改进建议时，说明其他可能解释、还需什么证据，
以及可以先验证的小动作。不要把几个人的回答写成市场比例。
```

**审查一份报告：**

```text
请使用 consumer-interview-research 审查这份报告及所附原始记录。
逐项判断关键结论是否有证据，检查引文上下文、样本计数和反例，
给出保留、修改或暂缓的理由及可直接替换的表述。
没有原始记录的部分，只做逻辑审查，不宣称已核验真实性。
```

如果工具没有识别技能名称，请明确让它读取安装目录中的 `SKILL.md`，再按其中的指引处理当前任务。

## 用于连锁卤味时

可以直接说：“研究某连锁卤味品牌的顾客为什么减少购买，请结合卤味研究提示卡设计访谈。”

技能会按任务读取[卤味研究提示卡](references/braised-food-research-card.md)，重点检查：

- **有没有找对人：**研究减少购买，就要考虑过去买、现在少买的人，而不只找现有会员。
- **究竟改变了什么：**区分少吃整个卤味品类、换品牌、换门店和换渠道。
- **场景是否不同：**还原这一次买来给谁、何时怎么吃；同一个人可以有多个场景。
- **“贵”具体指什么：**结合产品、分量、实际支付、优惠和配送费，核对比较对象。

这些是研究线索，不能提前把消费者固定分成几类，也不能预设口味或价格就是流失原因。

## 怎样检查结论

技能要求从原始记录回查每条重要发现，区分消费者自述、研究者解释和待验证假设，保留不支持主要结论的案例。需要行动建议时，先比较可能解释，说明什么证据会改变判断，再提出有条件的尝试及调整或停止条件。

例如，“消费者抱怨瓶口难清理”可以成为改善体验的线索；是否因此少买、是否愿意为新瓶多付钱，仍需另外取证。

配套脚本能检查引文是否来自指定受访者、是否逐字匹配、来源快照是否变化。**文本匹配不等于解释正确**：“如果免费我会买”里的“我会买”确实存在，但不能据此认定真实付费意愿。重要决策仍需研究者复核完整上下文。

## 使用边界

- 访谈适合理解经历、需求和可能原因，不能单独证明市场占比、销量提升、支付意愿分布或因果效果。
- 口味、气味、肤感的比较需要专门测试设计；健康功效、食品安全等不能靠消费者感受认证。
- 真实招募、主持、录音转录，以及长材料处理的质量仍需项目人员检查；不同模型和工具的输出可能不同。
- 请提供脱敏材料，按项目授权使用数据；不要把访谈记录或个人信息提交到这个公开仓库。

## 配套文件与引文核验

通常只需安装后提出任务。需要查看具体规则或核验引文时，再使用这些文件：

- [SKILL.md](SKILL.md)：AI 执行入口。
- [研究协议](references/research-protocol.md)：招募、提问、分析和结论检查的具体方法。
- [卤味研究提示卡](references/braised-food-research-card.md)：卤味项目的可选补充。
- [来源与许可](THIRD_PARTY_NOTICES.md)：改编来源及其许可说明。

发布逐字引文时，可让 AI 按研究协议整理来源快照 `source.json` 和引文台账 `evidence.json`，保留原始记录，再运行核验。在技能根目录下执行：

```bash
python3 scripts/validate_evidence.py source.json evidence.json
```

JSON 格式见[研究协议的“材料接收与来源”](references/research-protocol.md#c-材料接收与来源)。脚本只读输入、没有网络调用；返回 `matched` 仅表示所列引文的文本归属与范围匹配，仍需逐条检查报告、台账和原始上下文。录音转录中的错听也需另行复核。
